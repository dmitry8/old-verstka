Как пользоваться

      
    

    

      
Что вставлять

      
Заголовок <h3> и html-таблицу с ингредиентами из редактора. Можно несколько пар «заголовок + таблица» подряд — каждая превратится в отдельный <recipe>.


      
Таблица из двух колонок

      
Первая колонка — название ингредиента, вторая — количество. Каждая строка становится <ingredient>.


      
Таблица из трёх колонок (с группами)

      
    
        
  • Строка с тремя ячейками открывает новую группу: первая ячейка — название группы, две остальные — первый ингредиент.
    • 
        
  • Строки с двумя ячейками попадают в текущую группу.
    • 
        
  • Если первая строка таблицы — с двумя ячейками, группа создаётся с пустым названием, строка подсвечивается.
    • 
        
  • Больше трёх ячеек в строке быть не должно — такая таблица пропускается целиком.
    • 
      


      
Как разбирается количество

      
    
        
  • 160 г → amount="160" unit="г" — число в начале уходит в amount, остальное в unit.
    • 
        
  • 1,5 ст. л. → amount="1.5" — запятая меняется на точку.
    • 
        
  • 1/2 стакана → amount="0.5", 1/3 → 0.33 — дроби переводятся в десятичную запись.
    • 
        
  • По вкусу, щепотка → amount="" unit="По вкусу" — текст без числа целиком уходит в unit.
    • 
        
  • 3 → amount="3" unit="" — число без единицы: ячейка подсвечивается, unit нужно заполнить руками.
    • 
      


      
Что ещё важно

      
    
        
  • Первая колонка переносится как есть — теги, форматирование и &nbsp; сохраняются.
    • 
        
  • Во второй колонке теги выбрасываются, &nbsp; считается пробелом.
    • 
        
  • Все атрибуты таблицы (width, class и т.п.) удаляются.
    • 
        
  • Текст вне таблиц и заголовков в результат не попадает и подсвечивается.
    • 
        
  • Заголовок <h3> любого вида превращается в <h3 level="3">. Если заголовка нет — таблица всё равно конвертируется, внизу появится сообщение.
    • 
      


      
Порции и единица

      
Поля «Порций» и «Единица» над правым полем подставляются в <recipe portions="…" unit="…">. Менять можно после конвертации — результат пересчитается сразу.


      
Ошибки

      
Проблемные места подсвечены оранжевым в левом поле — наведите курсор, чтобы увидеть пояснение. Ошибки, не привязанные к конкретному месту, показываются плашкой под левым полем. Всё, что можно, конвертируется — остальное нужно поправить руками.
